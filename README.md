# wwwant: тропа покупок (мини-апп и бот в Telegram)

Один репозиторий: сервер на Node 22 без зависимостей, SQLite, мини-апп (`web/index.html`), бот.

## Что умеет
- Мини-апп внутри Telegram хранит данные на сервере (вещи, цены, «отложили», фото, история «куплено»). Вне Telegram открывается демо на localStorage.
- Бот: согласие на обработку данных при `/start`, добавление вещи ссылкой и ценой одним сообщением, недельная сводка с кнопкой «+ обычная сумма как обычно» и отменой, `/week`, `/digest_off`, `/delete_me`.
- Сервер проверяет подпись `initData` (HMAC) на каждом запросе. Токен бота вводится один раз на странице `/claim`.

## Как запустить без терминала
1. Залей папку в свой репозиторий GitHub (кнопка Add file → Upload files, перетащить всё содержимое). Токены и пароли в репозиторий не кладём, `.gitignore` это закрывает.
2. Арендуй VPS в России с Ubuntu 22.04/24.04 или Debian 12. В панели хостера найди поле «пользовательский скрипт» (cloud-init / user-data) или веб-консоль и вставь одну строку:
   `curl -fsSL https://raw.githubusercontent.com/ТВОЙ_НИК/wwwant/main/deploy/install.sh | CLAIM_CODE=ПРИДУМАННЫЙ_КОД REPO_URL=https://github.com/ТВОЙ_НИК/wwwant.git bash`
   Код для страницы токена (10-40 латинских букв и цифр) придумай сама и запомни: он действует час, после ввода токена страница закрывается. Если не задать, код будет случайным и лежит в `/root/wwwant-claim.txt`.
   Репозиторий должен быть публичным (в нём нет секретов).
3. Установщик напечатает ссылку `https://…sslip.io/claim` и код (они же лежат в `/root/wwwant-claim.txt`). Открой ссылку, введи код и токен из @BotFather. Страница закроется сама.
4. Дальше обновления идут сами: сервер каждые 3 минуты смотрит `main`, прогоняет тесты, перезапускает и откатывается, если что-то сломалось. Правишь код на GitHub, на сервер руками ничего не нужно.

Адрес мини-аппки (`WEBAPP_URL`) подставляется автоматически, кнопка меню и команды бота ставятся при подключении токена.

## Что не проверено в боевых условиях
- `install.sh` и службы systemd проверены только синтаксисом, на живом VPS не запускались.
- Реальный Telegram не подключался: бот и API проверены на поддельном Bot API. Первый прогон на живом боте может вскрыть мелочи.
- Скрипт Telegram `telegram-web-app.js` грузится с telegram.org (разрешён в CSP). Остальное самохостится: шрифты вшиты в страницу.

## Безопасность: что сделано
- `initData` проверяется по HMAC, срок жизни 24 часа, будущие даты отбрасываются.
- Все данные привязаны к `tg_id` из подписи. Чужие вещи и фото недоступны (есть тест на IDOR). Фото отдаются по ссылке-ключу (HMAC от пользователя, вещи и версии).
- Ссылки на товары сохраняются как текст (только http/https), сервер по ним не ходит: нет SSRF и нет парсинга чужих сайтов.
- Все входные данные проходят строгую проверку (типы, длины, списки цветов, JPEG по сигнатуре, до 200 КБ). Лимиты: 60 вещей на человека, запросы в минуту.
- CSP со списком хэша единственного inline-скрипта (без `unsafe-inline` для скриптов), `frame-ancestors` только Telegram, `nosniff`, `no-referrer`.
- Служба под отдельным пользователем с ограничениями systemd, секреты с правами 0600, бэкап базы каждую ночь (14 копий, копия проверяется на открытие).
- Автообновление ставится от root из файла вне репозитория: кто получит доступ к GitHub, получит доступ к приложению, но не к root. Включи на GitHub двухфакторную аутентификацию и защиту ветки `main`.

## Что остаётся на тебе и на юристе
- Заполнить `/etc/wwwant/env`: `OPERATOR_NAME`, `OPERATOR_INN`, `OPERATOR_CONTACT`, `HOSTING_NAME`, затем `POLICY_DRAFT=0`. Это делается правкой файла в консоли хостера, один раз.
- Текст политики на `/policy` и формулировки согласия: черновик, их должен утвердить юрист.
- Уведомление Роскомнадзора об обработке персональных данных (ст. 22 152-ФЗ, исключений всего три: https://saby.ru/articles/contragents/uvedomlenie_o_personalnyh_dannyh_v_roskomnadzor).
- Хранение данных граждан РФ в России: сервер в РФ, формулировку закона по действиям с данными уточняет юрист (https://habr.com/ru/articles/943422).
- Включить автоплатёж за хостинг.
- Участник получает сообщения бота только после нажатия Start. Telegram в России может тормозить: сообщения идут через очередь с повторами. Для запасных адресов Bot API есть `TG_API_BASES` (список через запятую).
