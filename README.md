# wwwant: тропа покупок

Бот и мини-приложение для Telegram. Складываешь сюда вещи, которые хочется, расставляешь по зонам «Сейчас», «Потом», «Мечты» и копишь на каждую. Бот принимает ссылки с Ozon, Wildberries и Яндекс Маркета и присылает недельную сводку.

Работает на Cloudflare: Workers (код), D1 (база), cron (сводка и повторы). Сервер арендовать не нужно. Деплой автоматический: любое изменение в ветке `main` само уходит в бой.

## Запуск без терминала

1. **Бот.** В Telegram откройте @BotFather, команда `/newbot`, получите токен. Токен никому не показывайте и никуда не пишите, кроме шага 4.
2. **Cloudflare.** Зарегистрируйтесь на dash.cloudflare.com (бесплатного тарифа достаточно).
3. **Подключение репозитория.** Workers & Pages → Create application → Import a repository → GitHub → выберите этот репозиторий. Имя Worker оставьте `wwwant`, команду деплоя не меняйте (`npx wrangler deploy`). Нажмите Save and Deploy. База D1 создастся сама.
4. **Токен.** Worker `wwwant` → Settings → Variables and Secrets → Add. Тип **Secret**, имя `BOT_TOKEN`, значение — токен из шага 1. Нажмите Deploy.
5. **Проверка.** Откройте `https://wwwant.ВАШ-ПОДДОМЕН.workers.dev/health`. Должно быть `"status":"ok"`. Webhook, кнопка меню и команды бота настроятся сами при первом заходе, ничего вручную не делается.
6. Откройте бота, нажмите Start, пришлите «Лампа 4300».

Если на шаге 5 видно `waiting-token`, токен не сохранился: повторите шаг 4. Если `setup-pending`, Telegram не ответил с первого раза, обновите страницу через минуту.

## Что где

- `server/worker.js` — вход в Cloudflare: подключает базу, токен и страницу приложения.
- `server/app.js` — все маршруты: приложение, `/api/*`, `/tg` (webhook от Telegram), `/policy`, `/health`.
- `server/bot.js` — бот: согласие, добавление вещей, кнопки, сводка.
- `server/db.js` — база (D1). Таблицы создаются сами при первом запросе.
- `server/outbox.js` — очередь исходящих сообщений с повторами. Cron раз в минуту подбирает застрявшие.
- `server/digest.js` — недельная сводка, по умолчанию воскресенье 18:00 по Москве.
- `web/index.html` — само мини-приложение.
- `wrangler.toml` — настройки Worker. Не секретные значения (контакты оператора, название хостинга для политики) правятся здесь, прямо на GitHub.
- `test/` — 38 тестов. Запуск: `node --test`. Они же идут в GitHub Actions на каждый пуш.

## Безопасность

- Токен бота лежит только в секретах Cloudflare: не в репозитории, не в базе, не в логах.
- Запросы мини-приложения проверяются по подписи Telegram (HMAC) на каждом вызове. Webhook принимает только запросы с секретом, который Worker сам задал при настройке.
- Строгая политика CSP, запрет встраивания в чужие страницы, нет внешних скриптов, кроме telegram.org.
- Фото отдаются по ссылке с подписью, чужие вещи недоступны (проверено тестами).
- Лимиты на запросы стоят, но считаются внутри одного экземпляра Worker. Для закрытого теста этого достаточно; перед открытым запуском их стоит усилить правилами Cloudflare.

## Что учесть перед публичным запуском

- **Место хранения данных.** База D1 лежит у Cloudflare, не на сервере в России. Для теста на своих данных это нормально, для публичного запуска с пользователями из РФ вопрос о локализации персональных данных (152-ФЗ) нужно решить с юристом. Политика на странице `/policy` сейчас черновик.
- **Доступность в России.** Часть провайдеров может тормозить или блокировать Cloudflare. Проверьте открытие `/health` и самого приложения с мобильного интернета без VPN.
- **Лимиты бесплатного тарифа.** 100 000 запросов в день на Worker, ограничения на чтение и запись в D1. Актуальные цифры смотрите в документации Cloudflare.
- Бот пишет только тем, кто нажал Start. Это стоит сказать пользователям в интерфейсе.
